Faz 4+5+6: Is Emri, Dashboard widget sistemi ve Sistem Yonetimi

FAZ 4 (Is Emri Yonetimi):
- Backend work-order modulu: CRUD + WO-YYYYMMDD-NNN otomatik numara + TRANSITIONS durum makinesi
  (draft->active->paused->completed->archived) + canTransition guard (409 INVALID_TRANSITION)
- DataCollector: worker verisi -> data_log (1sn transaction batching, quality/value_text,
  recipe_tags + dashboard widget tagId/tagIds union, active/paused WO resume on boot)
- Frontend: WorkOrderList (durum filtresi + durum bazli aksiyon butonlari) + WorkOrderForm (recete secimi)

FAZ 5 (Dashboard):
- 5 widget render bileseni: Numeric, Gauge (custom SVG arc), Trend (Recharts), Status (LED), Table
- useLiveValues(plcIds[]) hook (multi-PLC subscription), DashboardSelector (aktif WO kartlari),
  DashboardView (view-only 12-col absolute grid, canli WS verisi)

FAZ 6 (Sistem Yonetimi):
- user-management: user CRUD (bcrypt, last-admin guard, must_change_password) + /api/permissions
  (operator role module x permission matrisi)
- system-settings: settings (key-value), modules (enable/disable -> restartRequired),
  archive (interlock on active WOs, full DB copy, yalniz data_log temizlenir), audit (paged query)
- Frontend: UserList+UserForm+PermissionEditor, SettingsPage (Branding+ModuleManager)+ArchivePanel,
  AuditLogViewer. Rotalar /users, /settings, /audit

i18n: workOrder, dashboard, users, settings, audit anahtarlari (tr+en)
End-to-end dogrulandi: WO activate -> data_log kayitlari; canli dashboard widget'lari;
yetki matrisi; arsiv interlock; audit girisleri. Typecheck + build temiz (PWA 35 precache).
